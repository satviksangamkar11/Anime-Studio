## PROVEN chip + prompt recipe (Claude did SHOT-001A this way, 2026-11-08) - use the pane's NORMAL size (do NOT use resize_window 1280: clicks land wrong, picker differs)

2. Chips, one at a time, in the job's order: `type` the single character "@" (nothing else), wait 3 s, screenshot. A full-screen asset list opens (rows: title + "Image"). Click the row whose title is EXACTLY the chip name: either click its coordinates from the screenshot, or `find` the exact title and left_click the ref that sits inside the list. If the row is not visible, use `scroll` in the list or the list's Search box (click the box first, then type); if typed text lands in the prompt instead, ctrl+a, Backspace and start again. Do NOT click the "+" / "Add ingredients" button.
3. After the LAST chip, `type` the full job prompt text (the `prompt` field, exact) with the computer `type` action (it appends after the chips; form_input would wipe the chips).
4. Check: three/four/five thumbnails above the box = the chips; settings bar shows Nano Banana 2.1, the portrait icon (9:16) and x2. Click the round arrow button at the bottom right to submit once. Tiles show a percentage while generating; wait ~60 s.
5. The composer keeps the old prompt after a submit: for the next job clear it (click the box, ctrl+a, Backspace; chips vanish too) and repeat from step 2.
