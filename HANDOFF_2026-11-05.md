## How the 2K download works (the browser pane drops downloads)
The built-in browser pane never saves Flow downloads (no Save dialog, nothing in Downloads). Working method used today:
1. Open the tile's edit page; in `javascript_tool` hook `HTMLAnchorElement.prototype.click` so a download click fetches the blob into `window.__dl` as a data URL (name = Flow's file name, e.g. `LEAP-01A__v01_79781719_2K.jpg`).
2. More options (⋮) -> Download media -> 2K Upscaled; wait ~20 s.
3. Return `JSON.stringify({name,data})` from `javascript_tool`; the result is too big, so the tool saves it under `...\.claude\projects\D--aai-work\<session>\tool-results\*.txt`.
4. Decode with `flow/scripts/save_dl.py <tool-results txt files>` (regex for name + base64 -> `C:\Users\Satvik\Downloads\<name>`), then `download_queue.py collect`.
