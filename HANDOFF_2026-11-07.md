## 1. What this project is
Anime Studio turns a story (pasted text, or a YouTube link) into short vertical anime reels (9:16, 60-75 s each) through a pipeline with human approval gates. Repo: `satviksangamkar11/Anime-Studio` (PUBLIC: never push images, clips, weights, keys, transcripts or the `stories/` folders; `.gitignore` already blocks them). NEVER touch `D:\aai work\granthstudio` (other project; read-only if needed).

Pipeline: Story (paste / YouTube link: captions first, Whisper second) -> Writer (staged, free model) -> pack (PACK.md, bible.json, shots.json) -> **pack_validator (new)** -> **Gate A** (owner approves plan) -> image jobs (pack_to_spec + build_jobs) -> Flow images (Haiku LOW agents, AI reviewer, watermark removal, 2K) -> **Gate B** -> read-out -> **Gate C** (type START) -> H3 router/compiler/linter -> Colab render (spend gate) -> Gate D audio/captions mix -> **Step 9 final QC** -> export.
