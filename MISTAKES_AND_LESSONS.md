## 5. The rules that matter most (short list)

1. Prove the script started within 3 minutes of `--go` (`colab ls /content` shows `out/`), else stop the session.
2. Save every clip to the PC the minute its shot ends. Never wait for the end of the run.
3. Run ONE shot for real first; look at its clip; then the rest. A dry run is not a test.
4. Always stop the session; check `colab sessions` and `colab usage` after every run, and never touch the session that is not ours (the owner's T4 browser notebook).
5. The proven GPU is the G4. Do not change GPU, model or prompt layout without a one-shot test.
6. Prompts: single line breaks only, no blank line (Wan2GP).
7. `colab exec -f` hangs above about 7 MB on this PC: upload in 3 MB parts; run.py stays small.
8. Review the render script with ALL reviewers before `--go` (note N3), then fix, then start.
9. Keyframes: open every kept picture at full size; A/B pairs are start and end of ONE shot, check them side by side (note N4); reworks are single-reference edits.
10. Flow agents: own tab, `tabId` on every action, retire before you rename, one tile per title, screenshot before a click.
11. Code with backslashes: Edit tool, then `ast.parse`. Never a heredoc.
12. A log line is written after the result is read, not before. Corrections are new FIX lines.
13. Opus and Sonnet CLI can run out for days (weekly limit): plan authoring and reviews on the free Super model.
14. When the owner says stop, stop first.

See also: `blot.md` rules 20 to 31, `Satvik notes refer.md` (N1 to N4), `PROJECT_LOG.md` (every step), `CLAUDE.md`.

## 7. VOICES, STAGING AND FILE CHECKS (2026-11-09, found while building the voice system)
V1. LOGGED AN EDIT THAT NEVER HAPPENED: the Write of director/voice_library.py and its test was blocked by the worktree path guard, but the PROJECT_LOG line said "EDIT ... done". Check with ls (or read the result) before logging a file as written; a correction is a new FIX line.
V2. WRONG CLAIM TO THE OWNER: I said the account has no Hindi voice. The saved Granth library (canon/series/voices.json) shows eight male voices verified for BOTH Hindi and Marathi. Search the saved library BEFORE saying a voice type does not exist.
V3. REWROTE WHAT COULD BE COPIED: I started a new voice_library.py. The owner asked to copy Granth's code with minimal change. Copy source/a1_eleven.py first (job key, ledger, reuse, ffprobe, measured, export); change only plan loading, languages and paths (director/voice_cast.py, 5 offline tests).
V4. PHONE SHOWED NO AUDIO: several ElevenLabs preview files were WAV data named .mp3 (RIFF header), which a phone player shows as silent. Before sending audio check the header (ID3/mp3) with ffprobe format_name and re-encode to a real mp3 (libmp3lame 128k mono).
V5. A PREVIEW IS NOT A TEST: preview_url is the voice's own demo clip, usually not Hindi or Marathi and never our names. It says nothing about pronunciation, speed or the sacred names.
V6. PRE-FLIGHT FOUND FIVE BLOCKERS BEFORE ANY CREDIT WAS SPENT: (1) 16 of the 18 cast voices are shared-library voices not in the account, Starter has 10 voice slots; (2) Hindi Victor, Frederick, Edward are verified for hi only on eleven_multilingual_v2, not eleven_v4, so one model for all fails (v2 reads no emotion tags); (3) rate 2.0 voices (en Carter, en Matthew Schmitz, hi Frederick) may cost double; (4) 9 Hindi lines run 3.24-3.57 words per second against the 3.2 limit; (5) hard names untested. Always run the free pre-flight (account, slots, per-voice verified languages and model, rate, words per second per slot) before the first paid call.
V7. STAGING WAS NOT CHECKED AGAINST THE SCRIPTURE UNTIL AFTER THE RENDER: the Sanskrit check showed SHOT-007 should show Daksha/sages reacting and SHOT-009 should show Shiva present when Kama shoots Brahma; both rendered clips lack them (action text shows only Sandhya/Brahma and Brahma/Kamadeva). Check each shot's script against the source for omitted details BEFORE keyframes are made and say what the picture must show.
V8. DISK: the C: volume that holds Claude's temp folder reached 1 MB free (2026-11-09). Free space on C: before long jobs; never delete the owner's files to make room without telling them.
V9. WORDS-PER-SECOND DID NOT PREDICT FIT: the 3.2 w/s rule passed on paper but real clips from slow dramatic voices ran at 1.7-2.4 w/s, so 19 of 32 batch-1 clips overran their slot (up to 2.6x). Before a full paid run, generate ONE real line per voice (the hardest slot) and measure seconds against the slot; set voice speed and text length from that.
V10. A SETTING IS NOT PROVEN UNTIL ITS RESULT IS MEASURED: ElevenLabs voice_settings speed 1.15 returned clips of the same length (4.08 -> 4.16 s). Test any quality/speed knob on one cheap clip and measure before promising it as the fix; I told the owner speed + shorter text would solve it before testing.
