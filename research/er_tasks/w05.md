Edit score/cue_sheet.py only (tests are frozen in score/tests/test_cue_sheet_lock.py; do not touch test files). Changes:
1. New function `apply_lock(shots, lock)` placed right before `build_cue_sheet`: returns (new_shots, errors). Errors use the module's `_err(code, where, message)` helper. If lock is not a dict or lock.get("shots") is not a list: return (shots, [_err("LOCK_SHAPE", "lock", "expected a timeline lock with a shots list")]). fps = lock.get("fps", 24). frames = {shot id: edit_frames} from the lock rows (skip rows that are not dicts with a str id and an int edit_frames; ints only, not bool). For every pack shot (dict with "id") that is not in the lock: error LOCK_SHOT_MISSING with where = the shot id. For every lock shot id not in the pack: error LOCK_SHOT_EXTRA with where = that id. Otherwise new shot = dict(shot) with "editorial_duration_sec" = edit_frames / fps. The input shots are not changed.
2. build_cue_sheet gets a new keyword argument `timeline_lock=None`. When it is not None and shots is a list, right after the editorial block (the same place, same style): shots, lock_errors = apply_lock(shots, timeline_lock); errors += lock_errors; if lock_errors: return None, _report(errors, warnings). Passing both editorial and timeline_lock: errors.append(_err("LOCK_AND_EDITORIAL", "lock", "give the lock or the editorial plan, not both")) and return None, _report(errors, warnings) before anything else.
3. main(): new option `--lock` (help: "timeline_lock file: shot lengths = edit_frames / fps"). If both --lock and --editorial are given: print("--lock and --editorial cannot be combined", file=sys.stderr) and return 2. Read the lock file like the editorial file (same try/except, same message style, return 2) and pass timeline_lock=<dict> to build_cue_sheet.
Do not change anything else.
