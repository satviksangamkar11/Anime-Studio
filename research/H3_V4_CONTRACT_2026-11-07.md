## Module API (fixed names so agents can work in parallel)

- `h3/router.py` (agent C): `route_shot(shot) -> str` (0 images T2VA, 1 start I2VA, 1 end L2VA, 2 boundary FL2VA, reference cards without boundary lock Ref2VA); `ref2va_limits_ok(...)`.
- `h3/compile_h3_sing8.py` + `h3/schema_and_linter.py` (agent C): Ref2VA 6-section compile, `strip_tags(text) -> (clean, removed)`, prompt lint codes: `SL-01` speech id `(S\d+)` incl. `(S1,S2)`, `SL-02` `[Language]` tag, `SL-03` `<d>` wrapper, `AU-01` `<Audio N>`, `TG-01` Flow chips (@CHAR-*, SHEET-*, ENV-*, STYLE-*) or bracket storyboard tags `[char:]`,`[scene:]`,`[shot:]`,`[dur:]`,`[hook:]`, `TX-01` unrequested double-quoted on-screen text (diegetic text allowed only when requested and <= 1 per shot), `LEN-01` > PROMPT_CHAR_LIMIT, `MO-01` missing mouth-closed lock ("while his lips remain completely closed") or `narrator_mouth_closed` not true, `SX-01` per-second SFX missing in the action sentences or `overall_soundscape` not 1-4 English sentences. Profiles (`h3/profiles/*.json`) carry `video_shift` (6.0 keyframe / 12.0 Ref2VA) and `audio_shift` (3.0) as configurable parameters.
- `h3/fallback_policy.py` + `h3/asset_manifest.py` (agent D): `next_action(shot_id, attempts, failure) -> {"rung": 1..4, "action": ..., "prompt_prefix"?, "split_rows"?, "model"?, "human_choices"?}` (rung 1 re-render with the exact Reference Anchors block prefix; rung 2 shorten to <= 6.0 s and split into adjacent rows then re-run `self_check`; rung 3 switch to Seedance 2.0 1080p and log the model switch in the manifest; rung 4 human gate with HUMAN_CHOICES, never silently mixing corrected and uncorrected clips); `clip_key(bible_sha256, shot_row_sha256, start_frame_sha256, end_frame_sha256, model_id) -> str`, `is_stale(entry, current) -> bool`, `blocking_problems(manifest, current) -> [str]` (stale hash or unresolved `placeholder: missing clip` blocks assembly); resolution ladder `render_plan(clips, approved_ids)` (pass 1 base 864x1536, pass 2 1440x2560 only on approved clips, 1080p for Seedance fallback shots).
- `h3/step9_qc.py` (agent D): `final_qc(...)` with injectable measurers: (a) audio energy peaks vs column 6 sfx_cues time ranges, (b) visual continuity vs reference_anchors, (c) closing shot delivers the emotional-anchor payoff with a strong hook, (d) zero storyboard tags/labels on screen. - `h3/gate_d_audio.py` (agent E): opening vocal hook + narration density check (HOOK_NARRATION), closing shot contract, `vo_fit_check(...)` (`VO_OVERFLOW_ERROR`), `bgm_manifest` read/validate (`track_id, path, license_type, bpm, lufs`), `build_mix_filter(...)` (the exact 3-stem ffmpeg filtergraph text: aformat 48000 stereo fltp for all 3 stems, 5 ms anti-pop afade per trimmed H3 SFX clip, apad of the VO to total_reel_duration_sec, `asplit=3[vo_out][sc_sfx][sc_bgm]`, SFX duck `threshold=0.03:ratio=4:attack=10:release=350`, BGM duck `threshold=0.03:ratio=6:attack=15:release=500`, `amix=inputs=3:duration=longest:normalize=0,atrim=0:<total>`, then `loudnorm=I=-14:TP=-1.8:LRA=11`), BGM presence floor check (median ~15..21.5 dB under the voice and a non-silent p95 floor), post-AAC loudness verification from ffmpeg ebur128/loudnorm output (-14 +-0.5 LUFS, TP <= -1.5), `.ass` caption renderer (1440x2560 PlayRes, Alignment=2, MarginL=160, MarginR=160, MarginV=467, nothing above y=360, <= 6 words per card, active-word highlight, font NotoSansDevanagari-Bold.ttf referenced from `assets/fonts/`, fail clearly when the font file is missing; never download). ## ADDENDUM 2026-11-07: output languages (owner order)
The owner can select ONE language, any two, or ALL THREE of English (en), Hindi (hi), Marathi (mr) per story. Data model: story.json `output_languages: ["en","hi","mr"]` (subset, order = priority; `output_language` stays as the first/primary for old readers). CLI `--out-lang en|hi|mr|en,hi|...|all`. When more than one language is chosen the writer produces, for EVERY shot, a narration/dialogue/caption text per language: `audio_and_dialogue_track.narration` becomes `{"text":..., "language":..., "time_range":[s,e]}` for the primary language plus `narration_by_lang: {"en": {...}, "hi": {...}, "mr": {...}}` (and the same `dialogue_by_lang`, `captions_by_lang`), all with the SAME time ranges so one video track serves every language. Assembly (Gate D) renders one final reel PER selected language: its own ElevenLabs VO file set (`audio/vo/<lang>/<shot_id>.wav`, supplied by the owner), its own .ass captions (Latin font for en, Devanagari font for hi/mr), same H3 SFX stem and video; outputs `export/<reel>_<lang>.mp4`. VO fit, dead-air and loudness checks run per language. Validators check each language with its own tier (simple English, simple Hindi, simple Marathi). H3 prompts stay language-free (pure Foley).

Decision: `narration_by_lang`, `dialogue_by_lang`, `captions_by_lang` live INSIDE each shot's `audio_and_dialogue_track`. Validator codes ML-01..ML-08 and STORY-04 (see director/pack_validator.py).
