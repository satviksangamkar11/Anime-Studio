## B. Individual vs grouped / chained: facts
1. No test of two shots in one clip anywhere in the repo (V2_context_loop.md:252 "in-clip cuts untested (inference)").
2. H3 length limit: 107+17k frames at 24 fps, max 362 = 15.08 s (h3_director.py:33-34). Our shots are ~124 frames (~5.17 s). Two shots of 4-5 s would fit the limit, untested.
3. CHAINED seams exist (v4_to_h3.py:245-250, :443, :694-695): shot N+1 starts from shot N's end image, so shot N+1 cannot be rendered before N's end image exists (serial dependency; an error in N carries into N+1). Mixed static/dynamic cuts are blocked (:698-702). Static seams need trim_out == pixel_frames and zero handles (DECISION_H3_FIELDS_2026-11-07.md:7).
4. Rule 52: each shot gets its own route S / SE / SE+mid (arcs over ~1.5 s) / REF / POST; QA is per clip (rule 33).
5. Cost (Colab units): reel 1 = 9.0 total, 6.25 for the useful 10-clip render in one G4 session, ~2.75 wasted on failed starts (MISTAKES_AND_LESSONS.md:9-11); SHOT-008 re-render alone ~1.2 units (log 11-09 02:48); G4 rate 10.05 units/hour; per clip ~0.6 units (inference); setup ~82 s per session.
6. Consistency/morph evidence is per shot, not grouped: SHOT-008 A/B mismatch (log 11-09 02:20, fixed by re-render 02:48); SHOT-002 arm count changes mid-clip (GEMINI_PROMPT_START_END_FRAME_2026-11-10.md:21).
7. Voice sync: H3 renders no speech, so grouping does not change voice timing directly, but mouth_state keys are per shot per clip second (v4_to_h3.py:169-191); a two-shot clip would need a per-shot-span mouth state the code does not have (inference).
8. External: W4_transcript_tips.md:120,155: extending a clip with a reference changed the speaker's voice (T3 [10:59-11:04]).

## D. Recommendation
- Q1 Mouth: ONE sentence per shot built from the blocking sheet, naming each person: "A speaks with moving lips; B and C keep their lips completely closed." Use prompt_hygiene.mouth_sentence (exists). Drop MOUTH_LOCK_SENTENCE and the "figure" rule for any shot with two or more people on screen (compile_h3_sing8.py:27-29, :76). Remove the "except for non-verbal breaths" clause (v4_to_h3.py:189-190). Keep the per-second mouth_state only for the speaker, with the moving-lip window matching the voice slot. RISK: H3 never tested on a moving mouth; the sentence may give no movement or movement on silent people: test on ONE two-person shot as the canary before the batch. Inference: the speaker's lip window matters more than the wording.
- Q2 Grouping: INDIVIDUAL clips, one shot per clip, as the default. Facts: reel 1 ran that way and every failure was fixable by re-rendering one shot (~1.2 units); CHAINED seams make N+1 depend on N; rule 52 orders keyframes per shot; no grouped test exists; QA is per clip. Inference: grouping halves clip count and setup, but one bad frame re-renders two shots and span-based mouth/voice timing is new code. If a group is ever tried, test one 8-9 s two-shot clip (under 362 frames) on one G4 session and check the morph at the internal cut. SE + mid keyframe inside ONE shot for arcs over ~1.5 s is allowed (not grouping).
