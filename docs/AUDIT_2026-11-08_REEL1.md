## Gaps found (reproduced today)
1. HIGH. pack_to_spec REFUSES the writer's V4 shots ("unsafe set id None"): it reads shot.set, shot.cast, shot.props and shot.keyframes, which V4 rows do not have. Gate B image prompts cannot be built from the new writer output.
2. HIGH. H3 prep: v4_to_h3 + linter report 73 lint errors on reel 1. 13 authored fields per shot are missing (the H3A author step has not run: expected). The rest are NOT authored fields: shots 2, 3, 6, 7 "no dynamic split fits" (editorial length vs lattice handles), shot 1 MO-03 and tail handle 14 (needs 24..47), shots 1 and 10 have a 7th second with no mouth state (MO-01) and only 5 of 7 sound cues (SX-01). The writer's validator never runs these H3 timing and seam checks, so a reel passes every writer gate and is still unrenderable.
3. MEDIUM. No speech-rate check before voice: 20 lines are above 3.2 words per second (English SHOT-003 4.4). The only fit check (Gate D vo_fit) needs the real wav, i.e. paid ElevenLabs first.
4. MEDIUM. Retention rules and check_pack measure the reel on pixel frames (70.8 s); pack_validator and the edit use editorial seconds (70.0 s). Rules with time windows (re-hook 25-35 s, cold open) are off by the handle frames.
5. MEDIUM. The story gate checks (active protagonist, crisis from flaw...) are graded by the writer itself with its own evidence strings. Nothing compares the script with SOURCE.md.
6. LOW. A story.json with no style_pack: the writer uses deva_neon, check_pack fails P1 (loud, not silent).
